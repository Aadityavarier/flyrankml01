Auditable Content Optimization: Leakage-Free Action Scoring at Scale

Aaditya Raghunath Varier • Machine Learning Engineering Track • Capstone Research Paper
Abstract

Organic search traffic decay frequently triggers unscheduled, uncoordinated editorial revisions with unmeasured business returns. This research evaluates supervised machine learning models to rank content assets for optimization using public-safe search performance logs. By enforcing a 5-fold entity-stratified group cross-validation scheme, we benchmark regularized linear models, Random Forests, and Gradient Tree Boosting against a deterministic baseline heuristic without identity leakage. Our empirical findings demonstrate that Gradient Tree Boosting achieves an observed mean ROC-AUC of 0.650 and PR-AUC of 0.634 across out-of-fold domains, providing reliable decision-support ranking. We translate these validated inferences into a capacity-constrained, rule-governed action playbook that explicitly defines human-in-the-loop review protocols and operational no-go boundaries.

1. Introduction & Problem Statement

Managing content performance across millions of search interactions presents a fundamental capacity allocation challenge. Editorial teams operating under fixed weekly bandwidth must decide which declining URLs justify high-effort rewrites versus low-effort metadata tweaks. Heuristic prioritization rules based solely on raw traffic drops frequently suffer from survivorship bias, cluster memorization, and lack of probability calibration.

This work builds an auditable, leakage-free prioritization pipeline. Designed strictly as a decision-support filter rather than an autonomous decision-maker, the system scores URLs and maps them into actionable archetypes with human-readable reason codes.

2. Data & Public-Safety Constraints

Experiments were developed using aggregated search performance logs spanning a standardized rolling 90-day observation horizon. In strict compliance with privacy standards:

  • Privacy Sanitization: All client domain names, proprietary query text, user sessions, and raw URLs were excluded prior to feature modeling.
  • Entity Abstraction: Accounts are partitioned using anonymous integer keys (entity_id).
  • Engineered Signals: Core features measure post-publication age in days (decay_days), percentage traffic degradation (traffic_drop_pct), and position-adjusted CTR deficit (ctr_gap_pct).

3. Methodology & Validation Design

Supervised modeling was preceded by strict task framing and data contract specification. To prevent data leakage and cluster memorization:

Validation Design

Standard random train/test splits allow data from the same account to appear in both partitions, artificially inflating generalization metrics. We enforce 5-Fold Stratified Group K-Fold Cross-Validation grouped by entity_id.

Leakage Audit

Features were checked against target and entity grouping keys. Linear correlations were capped at |r| < 0.85 to eliminate identity fingerprinting.

5. Limitations & Honest Framing

Claims are scoped within clear boundary constraints:

  • Non-Causal Scoring: Predictions represent statistical association with historical recovery patterns, not guaranteed causal lift.
  • External Shocks: Unobserved search engine core algorithm updates and macro seasonality fall outside feature boundaries.
  • Cold-Start Assets: Assets with fewer than 14 days of logged impression history fail data contract requirements and are excluded from automated scoring.

Human-in-the-Loop Review & Strict No-Go Boundaries

  • Zero Direct-to-CMS Automation: No model output may push live modifications without editorial sign-off.
  • YMYL Exemption: Legal, financial, and medical pages are strictly barred from heuristic rewrites.
  • Cannibalization Audit: Content teams must manually verify that refreshing an asset does not dilute rankings of active parallel landing pages.
